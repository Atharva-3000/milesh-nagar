# Dr. Milesh Nagar — Neuro & Spine Surgeon

Custom mobile-first static website concept created as a replacement/pitch site for the existing Dr. Milesh Nagar Neuro Spine Solutions domain.

## Files
- `index.html` — all page content
- `styles.css` — responsive visual system
- `script.js` — year + smooth anchor behaviour
- `assets/` — reserved for approved client imagery
